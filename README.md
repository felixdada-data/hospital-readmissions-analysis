# Hospital Readmissions Analysis

## Project Overview

This project analyzes hospital readmission data to identify patterns in readmission volume, hospital performance, medical conditions, and geographic differences across the United States.

The project was completed using **Microsoft Excel, SQL, Power BI, and Tableau**. Raw hospital data was cleaned, explored, transformed, and presented through interactive dashboards.

The purpose of the analysis is to show how healthcare organizations can use data to monitor hospital readmissions, identify high risk areas, compare performance, and support better patient care decisions.

## Project Objectives

The project answers the following questions:

1. What is the total number of hospital readmissions?
2. Which medical conditions account for the highest readmission volume?
3. Which states have the highest number of readmissions?
4. How does the excess readmission ratio vary by condition and state?
5. Which hospitals have higher predicted readmission rates?
6. How do hospital readmission outcomes compare across locations?
7. How can healthcare data be presented clearly for executive decision making?

## Data Cleaning and Preparation

The following steps were completed before creating the dashboards:

1. Reviewed the raw hospital readmissions dataset.
2. Removed or corrected invalid and missing values.
3. Converted readmission fields into the correct numeric data types.
4. Corrected errors affecting the display of states on maps.
5. Checked hospital names, facility identification numbers, and state abbreviations.
6. Standardized the readmission measures.
7. Separated the cleaned dataset from the original raw dataset.
8. Prepared the final data for SQL, Power BI, and Tableau analysis.

## Key Findings

The analysis revealed that hospital readmission volume differs significantly across medical conditions.

Some medical conditions contribute considerably more readmissions than others. These conditions may require stronger patient education, follow up care, medication management, and discharge planning.

The analysis also showed that readmission volume varies across states. States with higher readmission totals may have larger patient populations, more reporting facilities, or greater healthcare service utilization.

Most average excess readmission ratios were close to **1.00**.

An excess readmission ratio above 1.00 generally indicates that a hospital, state, or condition recorded more readmissions than expected. A value below 1.00 generally indicates fewer readmissions than expected.

States with high readmission volume were not always the same states with the highest excess readmission ratios. Therefore, readmission volume and readmission performance should be evaluated separately.
